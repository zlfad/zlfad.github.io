CRMKita

A production-grade, full-stack omnichannel CRM SaaS built at Trackerhero Sdn Bhd. Features include an omnichannel unified inbox, dynamic Kanban sales pipelines, automated lead routing, multi-tenant architecture, and real-time communication — deployed and serving real business customers.

Role

Software Developer Intern

Timeline

March 2026 – Present

Tech Stack

Laravel React Redis Inertia.js Radix UI

Live Product

crmkita.trackerhero.com

The Challenge

Trackerhero needed a unified, multi-tenant CRM that allowed SME clients to manage leads across multiple channels (WhatsApp, Email, Web Forms) without dropping conversations or losing revenue. Existing tools were fragmented — agents had to switch between platforms, and lead data was siloed per channel, creating blind spots in the sales pipeline.

The Solution

I independently developed the CRM module using Laravel for a robust, multi-tenant backend API, and React via Inertia.js for a snappy SPA-like frontend. Authentication, database workflows, business logic, and API integrations were all built from scratch. By leveraging Redis and Laravel Horizon, all connected clients receive real-time Kanban state sync whenever a lead is updated or moved.

Key Features

Omnichannel Unified Inbox

Centralised inbox aggregating messages from WhatsApp and Email into a single unified thread per lead — no more tab-switching.

Dynamic Kanban Pipelines

Drag-and-drop sales pipelines with real-time state sync via WebSockets. Any status change is instantly reflected across all active sessions.

Automated Lead Routing

Rules-based lead assignment automatically routes incoming leads to the correct agent or pipeline stage based on configurable criteria.

Multi-Tenant Architecture

Complete data segregation per tenant with shared infrastructure — each business operates in total isolation while running on the same platform.

Outcomes & Learnings

Deploying to a live production environment serving real businesses taught me invaluable lessons about multi-tenant database scaling, handling real-time state with Redis queues, resolving service-layer bugs without disrupting active operations, and writing technical documentation for client onboarding. This project is the most comprehensive full-stack system I have independently built to date.
